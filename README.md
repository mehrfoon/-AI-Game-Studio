# AI Game Studio

استودیوی هوشمند بازی‌سازی مهرفون؛ محیطی ابری و مرحله‌ای برای تبدیل ایده به بازی قابل اجرا.

## وضعیت فعلی
**مرحله ۱: زیرساخت و نقشه راه اولیه.** این مخزن فعلاً مشخصات پروژه، نقش عامل‌های هوش مصنوعی و گردش‌کار ساخت بازی را نگهداری می‌کند. هنوز مدل‌ها/APIها متصل نشده‌اند و هیچ بازی‌ای به‌صورت خودکار ساخته یا منتشر نشده است.

## هدف
1. دریافت و شفاف‌سازی ایده بازی
2. تقسیم کار میان طراحی، داستان، مراحل، هنر، برنامه‌نویسی، صدا و QA
3. نگهداری کد و دارایی‌ها در GitHub
4. اجرای تست و ساخت خروجی
5. آماده‌سازی خروجی وب، اندروید یا PC با تأیید مالک

## ساختار
- `docs/`: معماری و نقشه راه
- `agents/`: نقش و دستورالعمل عامل‌ها
- `config/`: تنظیمات استودیو
- `templates/`: فرم تعریف پروژه
- `.github/workflows/`: گردش‌کارهای خودکار (در مراحل بعد)

## محدودیت‌ها و امنیت
- سهمیه رایگان سرویس‌های ابری محدود و قابل تغییر است.
- کلید API فقط در GitHub Actions Secrets نگهداری شود؛ هرگز در کد عمومی قرار نگیرد.
- ساخت APK به Android SDK، قالب خروجی موتور و تنظیمات امضای امن نیاز دارد.
- موتور بر اساس نیاز هر پروژه انتخاب می‌شود؛ Godot گزینه اولیه است، نه انتخاب اجباری.
- هیچ عامل یا گردش‌کاری بدون تأیید مالک نباید هزینه ایجاد کند، فایل اصلی را حذف کند یا نسخه‌ای منتشر کند.
